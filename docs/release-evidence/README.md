# Release and acceptance evidence

This directory holds the stable files that release and acceptance claims cite.
It is not a task log; per-task raw runs live in
[`../evidence/`](../evidence/). Current status is stated in
[`../HANDOFF_CHECKLIST.md`](../HANDOFF_CHECKLIST.md).

## What lives here

| Group | Files | Purpose |
|---|---|---|
| Language / acceptance gate | `B030-*`, `B030-release.md` | Seven-language matrix, AT066/AT067 linkage, medium projects, rename and runtime evidence |
| Install / packaging gate | `B031-*` | Install, upgrade, rollback, uninstall, clean-machine index, offline report and VSIX |
| Handoff | `B032-handoff.json` | Generated by `tooling/handoff_check.py`; HEAD, clean state, task status and next actions |
| Task gates | `B016-*` … `B029-*` | One stable summary per accepted task slice |
| Upstream | `UPSTREAM-*`, `ROLLBACK-DRILL-*`, `ADAPTER-DRILL-*`, `LOCKFILE-PORTABILITY-*` | Pin checks, drills, rollback and adapter compatibility |
| Cross-cutting | `CROSSREVIEW-*`, `PRIVACY-DECOUPLING-*`, `SELF-ANALYSIS-FIX-*`, `WINDOWS-VERIFICATION-*`, `SURFACE-RETIRE-*` | Review closure, environment-specific verification and retired surfaces |
| Agent surfaces | `M1-*`, `M2.5-*`, `E1-*`, `E2*`, `E4A-*` | Onboarding and cognition-map experiments, including the E4a no-go |
| Publication | `PUBLIC-SNAPSHOT-*.json` | Private snapshot publication evidence; omitted from the public export |

## Naming and re-runs

- A gate file is stable: `B030-language-matrix.json` always means the current
  accepted language matrix, not the first run.
- A re-run that changes the result is recorded in a new dated task directory
  under `docs/evidence/`, cited from the gate file's `command`/`evidence`
  fields. Do not silently overwrite the old JSON.
- A gate file must name the command ID, HEAD and snapshot it was produced from.
  If it does not, the claim is not reproducible.
- `B032-handoff.json` is regenerated output. Regenerate it; do not hand-edit.

## Which file decides what

| Claim | Authoritative file |
|---|---|
| Seven-language acceptance | `B030-language-matrix.json` |
| Install/upgrade/rollback | `B031-install-tests.json` |
| Release notes and limitations | `B030-release.md`, `B031-release-notes.md` |
| Current task state and next actions | `B032-handoff.json` plus `../HANDOFF_CHECKLIST.md` |
| Upstream pin and release-only rule | `../upstreams.lock.json`, `UPSTREAM-STATUS-*.json` |
| Public publication | `PUBLIC-SNAPSHOT-*.json` (private), `../evidence/privacy-decoupling-*` |

## Rules

- Evidence is append-only. A failed or superseded run stays in the record.
- Do not change a `status` field without a real command record and a new run.
- Do not copy private paths, hostnames or dataset names into a file that will be
  published; the snapshot exporter scans and redacts them.
