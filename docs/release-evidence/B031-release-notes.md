## Platforms

- Windows 11 x64: built with Rust 1.94.1 GNU; CLI install/upgrade/rollback/uninstall, clean-prefix indexing, offline report export/verification and a headless Chrome offline render were tested on this machine.
- Ubuntu 24.04 x64: Linux binaries built in `rust:1.94.1-bookworm`; install/upgrade/rollback/uninstall, clean-prefix indexing, report export/verification and static offline HTML checks were tested in an Ubuntu 24.04 container. A rendered Ubuntu browser and VS Code host/UI were not tested there.
- macOS: not built, not tested, not supported in R1.
- No model provider is required; no telemetry and no remote web assets.

## Not tested / limitations

- Linux GUI/VS Code host integration is untested.
- The Ubuntu offline report was inspected as static HTML; the rendered browser check ran on Windows Chrome headless.
- The upgrade drill uses a locally built 0.0.9 bundle, not a published historical release.
- AT077 real newer-upstream upgrade is blocked: `git ls-remote upstream HEAD` still returns the pinned commit. The synthetic interface drill passed.
