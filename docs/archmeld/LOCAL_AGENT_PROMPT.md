# 可直接交给本地 Agent 的启动指令

请根据本文件所在目录的 ARCHMELD 初始化包开始构建产品，不再写一份泛泛的方案。

先读取 AGENTS.md、START_HERE.md、docs/00_BLUEPRINT.md、docs/01_FOUNDATIONS.md、docs/02_REUSE_AND_REPO_MAP.md、execution/FIRST_SESSION.md 和 execution/work-items.json。以 CodeGraph 固定提交为起点做薄分叉，保留并验证上游可复用能力；按任务依赖推进，最先完成真实源码索引、证据账本和源码/图联动的纵向切片，之后继续完成运行态、目标架构、受控重构、独立验证与双模式持久化。

首版必须满足 execution/RELEASE_GATES.md，不得把仅静态图、仅 Python 支持、假数据界面或未经验证的补丁叫完整 R1。底层分析器不足时修复适配或使用已指定语义工具，不退回文本匹配伪造调用关系。

采用默认单主 Agent、单写入者；不要求我每做一步确认。对需要上传源码、额外付费、执行未授权脚本或访问真实外部系统的动作，单独说明权限请求。无需权限且可执行的调查、实现和验证应继续完成。

每项任务完成后运行验收，保存机器可查证记录并更新进度。验证失败要定位原因；没有执行或没有依赖必须明示，禁止虚报。修改契约、依赖版本或设计基线需留有 ADR。工作结束时给出实际构建产物、真实测试结果、已知缺口及可直接继续的状态，不用建议清单代替已经授权的实施。
