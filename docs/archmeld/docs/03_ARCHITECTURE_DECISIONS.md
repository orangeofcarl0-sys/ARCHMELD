# 冻结架构决策（ADR）

每项状态：Accepted for implementation；不是已实现声明。修改必须追加 ADR，不覆盖历史。

| ID | 决定 | 理由与代价 |
|---|---|---|
| ADR-001 | CodeGraph 固定源码薄分叉 | 复用 parser/server/extension；承担上游兼容与隔离 patch |
| ADR-002 | Rust 单体核心，SQLite + 对象存储 | 与底座一致、状态统一；Python 工具只作进程适配 |
| ADR-003 | 底层分析器可替换，独立 EvidenceBatch | 不绑定后端图 ID/数据库；需要规范化与 provenance |
| ADR-004 | 证据/Claim/架构/变更分层 | 防止模型推断污染事实；增加显式关联 |
| ADR-005 | Manager/Expedition 同核 | 一次性不降级；需要导出、提升和清理生命周期 |
| ADR-006 | SCIP/LSP 语义增强，不把引用当调用 | 不重造编译器；需逐语言测试与平台差异处理 |
| ADR-007 | Runtime 以场景绑定，保留原始与有损标志 | 不用静态图冒充运行；转换与时钟需要严谨处理 |
| ADR-008 | 现有扩展+本地图/Timeline，不自制 IDE | 加速交付；需移除冲突上游入口和网络默认 |
| ADR-009 | 暂存区 + 冻结契约 + CAS + journal | 无多文件原子假设；应用与恢复实现必须仔细 |
| ADR-010 | 单主 Agent、单写入者、只读辅助 | 控制复杂度；不能掩盖外部用户写入 |
| ADR-011 | Instigator 异步非阻塞且无任务权限 | 推进深度不改变范围；消息可过期丢弃 |
| ADR-012 | 默认离线、无遥测、显式执行信任 | 降低出站/执行风险；首次依赖准备需独立步骤 |
| ADR-013 | 七语言能力分别验收 | 不按 parser 数宣传；完整 R1 发布须过全部最低套件 |
| ADR-014 | 内部纵向切片，不削弱 R1 门禁 | 早获得真实可用进展；中间版本不能冒充完整首版 |
| ADR-015 | 不继承之前原型的代码/测试结论 | 避免未核验基线污染；旧原型只可另行审计后摘取 |
| ADR-016 | 仅工具版本/二进制在本地 B001 完整锁定 | 不编造无法取得的哈希；未锁依赖不允许进入发布 |

关键非决策：不规定用户必须选某家模型；不强制所有程序容器化；不保证任意动态特性静态可解析；不默认重构一定比不改更好。
