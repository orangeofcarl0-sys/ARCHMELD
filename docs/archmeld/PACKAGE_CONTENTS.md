# 交付内容与使用顺序

## 入口

START_HERE.md：本地Agent先读。LOCAL_AGENT_PROMPT.md：可以直接粘贴的启动指令。AGENTS.md：开发与安全约束。README.md：索引和诚实边界。

## 规格

19份详细spec，4份总体/选型/复用/ADR文档。重点是两模式、固定快照、来源、七语言、运行场景、职责与架构、可编辑目标模型、变更事务、独立验证、Agent接入、安全、持久化、包装与数值域。S19规定Wire/hash/跨对象语义。

## 契约

23个JSON Schema文件（主文件包含72个定义）；41项OpenAPI操作；14个MCP高层工具；状态机、适配器协议、七语言能力目标、SQL逻辑表、API责任映射。全部为待实现设计契约，不是现成服务。

## 实施与验收

33项构建任务，区分实现依赖和验收依赖；80项MUST要求及80项产品验收规格，均为not_run。首轮PowerShell/POSIX克隆与构建手册、分阶段路线、R1发布门禁、Agent运行手册、5份交接与审查模板。

## 示例与核查

26份有效合成契约对象、12份Schema负例、6份Schema合法但语义非法负例、哈希向量、合成源码/Trace和artifact映射。30条官方来源记录；两个主项目SHA固定，其他依赖需本地准确锁定。规格校验脚本与结果、SHA256文件manifest。

这些数字统计对应当前包版本。生产源代码不在包中；应从固定上游克隆开展开发。包中只有规格验证脚本与少量合成夹具，避免把初始化文档误当已交付产品。
