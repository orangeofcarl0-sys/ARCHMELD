# S08 · 工作台交互与视图验收

## 1. 信息布局

左侧使用 IDE 原生代码编辑器，右侧为图/机制视图，下方可切换 Evidence、Runtime、Plan、Checks。项目页显示当前模式、snapshot、构建配置、索引 coverage、任务与风险。聊天不是唯一状态容器。

主视图按用户当前问题局部展开，默认限制可见节点，保留展开/折叠与布局锚点。提供键盘导航、搜索、返回历史、缩放、邻居和路径展开。不能先展示全部节点“毛线团”，也不能只生成无法导航的图片。

## 2. 统一选择模型

Selection = project/snapshot + entity/claim/scenario/architecture element + optional source range + origin_view + correlation_id。选择更新经过核心解析和权限检查，避免 UI 双向联动循环。旧快照导航使用只读虚拟文档，显示历史标识与当前差异入口。[SRC-VSC-WEBVIEW]

选择符号：显示定义、引用、候选/已解析调用、相关运行实例、所属职责和验证。选择边：显示关系种类、来源、适用配置、证据范围、覆盖和未知。选择事件：显示当时源码、任务/线程、correlation、对应架构实体。选择目标节点：显示现状映射、目标职责、待迁移内容。

## 3. 图的视觉语义

syntax/semantic/runtime/human/model 关系有可辨别样式，并有文字标签；颜色不是唯一编码。当前/历史、确定/候选、目标/现状、完整/部分均须区分。折叠组件显示成员数与覆盖情况，不隐藏未解析边。图例与空状态常驻可访问。

图布局以 entity identity 为锚，增量添加不全量随机重排。跨版本比较突出新增/删除/迁移；高相似度映射仅显示候选，不能伪造移动已证明。

## 4. 图上编辑是设计意图

目标架构编辑提供组件职责、成员、依赖约束、状态归属及变更原因。拖节点只是更新 To-Be membership。删除目标边生成 remove_dependency intent；任何代码修改必须经过计划预览、契约和授权。

计划面板展示受影响文件/符号、读写集、证据缺口、验证命令、风险、恢复策略和准确 diff。与用户原有未提交差异分开展示。按钮 `Apply` 只能对 prepared 且前置检查通过的 ChangeSet 启用。

## 5. Runtime 和报告

时间线借助本地 Perfetto 嵌入/跳转，详细原生 Trace 可打开原工具但必须保持 scenario/run 关联。支持从架构组件筛选对应执行片段，从片段返回源码。Tracy 等有损摘要明确标识，原始 artifact 不丢失。

一次性 HTML 报告使用离线资源；嵌入 JSON 做安全编码，源码 HTML 转义，不执行代码片段。报告带版本与完整性 manifest；没有源码权限则保留解释与脱敏引用，不能靠读取生成者本机路径才能打开。

## 6. 故障与反馈

索引中可浏览上一稳定快照，但明显提示 stale；提供进度、取消和原因。没有模型、工具未配置、构建失败、Trace 未绑定分别有行动入口，不统一显示“暂无数据”。失败信息含可复制的诊断，不暴露秘密和全路径到远程。

R1 UX 必测：从选定函数跳组件/运行/测试再返回；修改文件后失效可见；未知调用不呈确定样式；任务取消及时生效；重启恢复选择；中文路径和长名字；全键盘完成核心旅程；无网络打开报告。
