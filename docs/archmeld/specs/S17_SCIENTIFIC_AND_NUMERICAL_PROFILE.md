# S17 · 科学计算与数值算法配置

## 1. 目标

为采集、测量、滤波、估计、仿真等程序保留数学语义，不把一般软件分层教条强加给算法。该 profile 基于通用模型增加契约与视图，不创建第二套核心。

## 2. 数据与状态属性

允许为实体/接口声明物理单位、shape、axis 语义、dtype、采样率、坐标/相位约定、时延和状态生命周期。声明与代码/测试绑定；自动推断只标候选。无需 R1 开发完整量纲推导引擎。

机制视图可展示采集 → 标定 → 变换 → 状态估计 → 输出，以及各阶段真实 buffer owner、时间窗、因果性与单位。明确区分测量精度、噪声、更新率和输出延迟；不能靠增加平滑降低 RMS 就声称无损改进。

## 3. 数值契约

比较标准可选 exact、absolute_relative、ULP、invariant、statistical。每项含适用数据、阈值来源、seed/重复次数和异常值规则。absolute_relative 按 `abs(a-b) <= atol + rtol*max(abs(a),abs(b))` 或显式另一定义执行。所有容差在 ChangeSet 执行前冻结。

测试至少包含确定性合成真值、真实记录（用户授权）、极限输入、空数据、NaN/Inf、初始状态、长时运行、动态阶跃/频响相关指标。统计检验必须有预先定义方法，不从多次噪声运行里挑最好结果。

## 4. 重构允许与禁止

可以隔离 I/O、明确状态所有权、消除重复单位换算、建立纯函数边界、保持数学表达顺序并改善命名。不能默认把线性计算拆成大量抽象类、引入无必要配置系统、改变更新顺序、隐式替换滤波器或扩大浮点容差。

数值优化/算法更换是 behavior_fix 或 architecture_migration 类任务，不混入纯 structural_refactor。性能变化与输出变化分开评价。

## 5. MATLAB 边界

MATLAB 属明确扩展路径，首版七语言发布不包含其完整语义重构承诺。可以导入文档、人工绑定状态/单位和已授权运行结果；缺精确符号工具时禁用安全语义重命名按钮。不以文本扫描把支持状态伪装为 verified。后续适配器许可、运行环境与商业 MATLAB 依赖单独审查。
