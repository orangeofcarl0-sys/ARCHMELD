# R1 发布门槛

“不打折”指承诺范围内闭环和证据完备，不是无限语言与任意程序的正确性证明。

## Gate 0 · 可追溯底座

固定 CodeGraph 源码 SHA；上游测试实际跑过；稀疏ID/cache隔离/无网络探测有实证；工具链与许可锁定；不得直接相信README语言数量或模型输出。

## Gate 1 · 双模式与交互

Manager 重启保存决策和历史；Expedition 未获批准不修改被分析项目；代码/结构/职责/运行视图可导航；离线报告可打开；一次性会话可提升而不丢证据。默认无模型也可用。

## Gate 2 · 七语言分项

C/C++、Python、JS/TS、Java、C#、Go、Rust 每组均要通过结构/定义引用/实际runtime关联/一项跨文件受控变更/构建测试。JS和TS分别记录状态。非必然可解析的动态调用可明确未知，但不能因此免除定义引用和实际运行测试。每组至少一个金标工程和一个固定提交的真实中型项目。

Windows 和 Linux 均需真实核心测试；语言工具原生不可用时明确受控worker或受支持原生替代并验证。禁止默默标记完整原生支持。Mac未测就未验证。

## Gate 3 · 修改与独立验证

准备与应用双层授权；冻结契约；哈希前置条件；应用日志；故障注入恢复；用户后续修改保留；required检查缺失不通过；验证绑定真实结果快照。状态机/范围/权限由代码实施，不仅由提示词约束。

## Gate 4 · 完整场景

真实C++/Python混合场景完成“问题调查—反例—目标设计—受控迁移—验证—离线复查”；同时跑数值域场景。不得以纯预制JSON截图代替真实运行采集。

## Gate 5 · 可交付

干净机器安装，依赖检查，离线资源，取消/预算，备份恢复，权限与红队，许可证/NOTICE/SBOM、包校验和、更新失败恢复、明确局限。未达性能目标须修复或在批准的规格修订后重验，不能擅自缩小测试集。

## 发布结论的计算

所有 release_required 任务的所有适用MUST用例有真实passed记录，且每项结果绑定产品版本、平台、工具链和输入。环境未具备、not_run、unsupported、inconclusive不是pass；应阻止其所承诺的平台/语言完整发行。Instigator关闭可不阻止R1；启用必须通过B024验收。所有取消/故障/否定测试的“通过”意味着正确拒绝，而不是不发生故障。

结果表中保留通过/失败/未运行/不适用的数量与理由；不适用需有事先范围依据，不能用于绕过当前MUST。通过门槛后才创建发行标签；初始化包本身无产品发行标签。
